TaskFlow: building the system under test, then testing it from the outside.

TypeScript · REST API on SQLite · Web client · Expo mobile client · 2026, in progress

Open repo

The idea

Demo sites only go so far. TaskFlow is a small task manager for web, Android and iOS with one shared REST API, built so a separate automation suite can test it as an external consumer would: through the public API and the user interfaces, never the app's own code.

What's built

  • A pnpm monorepo with the task REST API on SQLite, the web client and the Expo mobile client.
  • Unit tests in Vitest and React Testing Library; route integration tests with Supertest against a test database.
  • CI on GitHub Actions, plus written docs for requirements, the API contract, deep links and decisions.

The test design

  • A boundary matrix for business rules, such as title lengths of 3 and 100 valid, 2 and 101 invalid.
  • Eight critical end-to-end journeys, including deep links and recovering from an API outage.
  • A locator contract: roles and labels first, data-testid and testID only where stability needs it.

The external suite is designed in the test strategy (PactumJS for API, Playwright for web, Appium with WebdriverIO for Android and iOS, k6 for load) and is meant to live in its own repository.

Android automation where every selector is proven, not guessed.

Appium · WebdriverIO · JavaScript · Android emulator · 2026

Open repo

The target

Sauce Labs' My Demo App for Android: login, catalog, sorting, cart and checkout, so there is enough real behaviour to test. It runs on a Pixel 6a emulator with Android 16.

Test design first

  • Ten test cases ranked by business risk, user impact and dependencies, covering positive, negative and edge cases.
  • A written test design that keeps designed cases separate from those already automated.

What's automated

  • Valid login reaching the catalog, and a locked-out user rejected with the expected error.
  • Catalog smoke checks, using screen objects so tests read as behaviour.
  • Every selector confirmed against the app's captured page source in each state.
